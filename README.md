# Whack-Shiki（神山识打地鼠）

一款可直接在浏览器及 GitHub Pages 上游玩的《Summer Pockets》同人主题打地鼠小游戏。

## 在线游玩

- GitHub Pages: `https://gdhjdsydh.github.io/Whack-Shiki/`

## 游戏特色

- **鸟白岛海滩镇魂碑场景**：高角度俯视沙地场景，正面可见「鬼姫神山識之鎮魂碑」，沙地上分布 3×3 共 9 个沙洞。
- **Q 版神山识角色与受击表情**：从沙洞中俏皮探出，被锤子砸中后会即时切换委屈大哭表情并触发打击特效与连击计数。
- **完整角色语音与 BGM**：
  - 击中随机播放 `Hit1~3.ogg`
  - 获胜播放 `Win.ogg`，失败播放 `Lose.ogg`
  - 全程循环播放 `BGM14.ogg`（支持一键静音切换）
- **多难度与双端适配**：提供简单 / 普通 / 困难三档难度，支持桌面端鼠标锤子跟随敲击与移动端触屏游玩。

## 本地运行

纯静态前端项目，直接通过任意本地静态服务器打开即可：

```bash
npx serve .
```
